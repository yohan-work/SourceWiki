# SourceLink Wiki 제품 개요

## 한 줄 소개

SourceLink Wiki는 AI 기술 자료의 URL을 저장하고 본문 추출과 로컬 LLM 요약을 거쳐, 출처가 분명한 지식을 공개적으로 축적하는 링크 기반 아카이브다.

## 문제와 사용자

AI 관련 문서·논문·블로그는 빠르게 늘지만 북마크에는 맥락과 학습 결과가 남지 않는다. 개발자는 같은 자료를 다시 찾고, 읽은 자료가 어떤 내용이었는지 반복해서 확인한다. SourceLink Wiki는 원본 URL, 정제된 본문, 요약, 개인 메모를 한 자료 단위로 묶어 재사용 가능한 지식으로 만든다.

주 사용자는 LLM, Agent, RAG, MCP 등 AI 기술을 학습하며 공식 문서·논문·기술 블로그를 자주 저장하는 개발자다. 자료와 댓글은 공개되며 비회원도 읽을 수 있다. 이메일 인증을 마친 회원은 자료와 댓글을 작성할 수 있고, 작성자만 자신의 콘텐츠를 수정·삭제할 수 있다.

## 핵심 가치

- 링크 하나로 자료 등록을 시작하고 출처를 항상 보존한다.
- 서버가 URL에서 본문을 추출하며 실패 시 URL만 저장하거나 원문을 직접 붙여넣을 수 있다.
- 로컬 Ollama가 요약 초안을 만들되, AI 장애가 CRUD를 막지 않는다.
- 요약은 결과가 아니라 수정 가능한 초안이며 원본 링크로 언제든 돌아갈 수 있다.
- 공개 아카이브 구조로 다른 사용자의 자료와 댓글을 함께 학습할 수 있다.

## 일반 게시판과의 차이

| 구분 | 일반 게시판 | SourceLink Wiki |
| --- | --- | --- |
| 작성 시작점 | 제목과 본문 | 원본 URL |
| 핵심 데이터 | 사용자 작성 글 | 출처, 추출문, 요약, 메모 |
| AI 역할 | 선택적 부가 기능 | 원문 기반 요약 초안 생성 |
| 실패 처리 | 해당 없음 | 추출·AI 실패와 무관하게 저장 가능 |
| 탐색 방식 | 글 목록 | 출처와 요약 중심 자료 카드 |

## 제출 버전의 제품 범위

제출 버전은 회원가입·실제 이메일 인증·로그인·JWT 세션·자료 CRUD·댓글 CRUD·서버 페이징·Swagger·Docker·클라우드 자동 배포를 완성한다. 차별화 기능은 안전한 URL 본문 추출과 로컬 Ollama 요약까지 포함한다.

검색, 좋아요, 파일 업로드, 프로필 편집, 관련 자료 추천·연결, pgvector, 지식 그래프는 제출 이후 범위다. 대시보드는 기존 API 응답으로 표현 가능한 최근 자료와 기본 수치만 사용한다.

## 성공 기준

- 처음 방문한 사용자가 서비스 목적과 공개 범위를 이해한다.
- 가입부터 이메일 인증, 로그인, 자료·댓글 CRUD까지 배포 환경에서 완료된다.
- 비회원은 공개 자료를 읽되 쓰기 기능에는 접근할 수 없다.
- URL 추출 또는 Ollama가 실패해도 사용자가 직접 내용을 입력하고 자료를 저장한다.
- GitHub 기본 브랜치 배포가 성공하면 HTTPS 서비스와 Swagger 문서가 갱신된다.
- 발표자가 상태관리, API 공통 처리, 쿠키 전달, 토큰 만료, DB 관계를 구현 근거와 함께 설명한다.

## 원문 저장과 공개 원칙

원본 URL과 출처 도메인을 중심 정보로 취급한다. 추출문은 정제된 텍스트만 최대 100,000자로 저장하고 HTML 원문은 저장하지 않는다. 목록에는 최대 300자의 미리보기만 제공하며 상세에서도 추출문은 접힌 영역으로 표시한다. 사용자는 저장 전에 추출문을 검토·수정할 수 있고 개인정보나 유료 콘텐츠를 저장하지 않을 책임을 안내받는다.
